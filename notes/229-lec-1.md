# Lecture 1 - Standford CS229 - Spring 2026

### Machine Learning: 
Field of study that gives computers the ability to learn without being explicitly programmed.

### Well-posed Learning Problem: 
A computer program is said to *learn* from experience E with respect to some task T and some performance measure P, if its performance on T, as measured by P, improves with experience E
- Basically, for a program to *learn*, it needs to get better given more experience


### Supervised Learning: 

Given inputs X and labels Y, the goal is to learn a mapping from X -> Y
- Simplest form is linear regression
- Next is probably a quadratic function

### Regression Problem: 
Problems where the value we are trying to predict (Y) is continuous

### Classification Problem: 
Problems where the value we are trying to predict (Y) can take on a discrete number of values


### Unsupervised Learning: 
Given inputs X and no labels, the goal is to learn some kind of structure

### Reinforcement Learning:
When a model does good, you reward it, when a model does bad, you penalize it, with the goal of controlling this over time, to do more desired actions than undesired

## Key Note: 
It would be good to learn machine learning *systematically*. Stop treating it like a black box, strategize how you use it.
